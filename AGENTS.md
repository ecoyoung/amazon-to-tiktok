# Oceanwing Insight Agent Repository Instructions

## Lessons maintenance

When a development defect, integration failure, or production incident is
resolved and the root cause has been verified:

1. Update `lessons.md` with the symptom, root cause, fix, validation evidence,
   and prevention.
2. Add or update the matching row in `lessons-summary.md` using:
   category, problem, common location/skill module, impact, and solution.
3. Update an existing lesson when the failure mechanism is the same; do not
   create duplicate entries for repeated symptoms.
4. Mark unverified diagnoses as pending validation. Do not present them as
   established solutions.
5. Never record real credentials, cookies, tokens, private URLs, or user data.
6. Complete the lessons update in the same task that closes the issue.
